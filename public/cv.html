Open Source
Claude Code Skills, Plugin Marketplace · Developer Tools
My own Claude Code plugin marketplace with 10 open-source skills, installed with one command, one at a time or as senior, student and all-skills packs. Each skill is a single SKILL.md that came out of a real project where an AI agent kept making the same mistake. github.com/iampreetdave-max/agent-skills
  • done-gate: an agent cannot call work done until every ask is rebuilt from the user’s own words, proven with file:line evidence, audited by a fresh subagent that is not told what changed, and passed through the project’s own checks.
  • loop-breaker: when the same error keeps coming back, stops the edits, reproduces the failure by hand, tests every assumption and proves the root cause before any fix; failing that, writes a handoff for a fresh session on a different model.
  • compliance-check: reads a codebase for personal data, third parties, payments and AI features, asks only what the code cannot answer, maps India’s DPDP Act, GDPR, the EU AI Act, HIPAA, PCI DSS and more, and pushes a prioritised fix list with file:line evidence.
  • honest-model-eval: a script audits the data for imbalance, ID columns and leak suspects; every feature is checked for availability at prediction time, splits are by time, the market is a baseline, and results are calibrated with their uncertainty.
  • doc-extraction: OCR whose numbers can be trusted: text layer first, OCR or a vision model only where needed, each page read with context from the one before, and deterministic validators (running balance to the cent, checksums, totals) deciding what is correct.
  • skill-scout: finds skills that fit a project on GitHub and plugin marketplaces, ranked by fit, then health, then stars, with their open issues and code read; counts which installed skills are actually used and says what to remove.
  • make-automation: Make.com and Python together, secured webhooks, human approval before anything goes out, nothing acting twice, dry runs and error handling.
  • android-device-test: tests an app on a real Android phone over adb, tapping real UI elements from the view hierarchy, cutting the network and killing the process, with pass or fail per flow, screenshots and logcat.
  • hackathon-sprint (hard category, open source and papers first, one flawless demo path, a real deployed URL) and exam-sheet (syllabus and past papers to one printable revision page, chapters ranked by the marks they carried).
